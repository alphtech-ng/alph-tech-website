# ALPH TECH Website

Professional, mobile-first website for ALPH TECH.

## Before publishing

1. Replace the image placeholders with your real ALPH TECH photos.
2. Add your final ALPH TECH logo.
3. Review all wording and contact details.
4. Test every page on a phone.
5. Test the contact form after publishing.

## Image folders

- `images/vffs/` — VFFS and packaging images
- `images/water-production/` — water and beverage production images
- `images/water-treatment/` — industrial/domestic water-treatment images
- `images/repairs/` — repair and maintenance images
- `images/projects/` — project portfolio images

The website is designed to run on GitHub Pages without a server.
